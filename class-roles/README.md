# 🌈 우리 반 1인 1역할

학생과 학급 역할을 무작위로 1:1 짝지어 주는 웹 앱입니다.
교실 게시판에 붙일 수 있도록 A4 한 장 인쇄도 지원합니다.

## 사용 방법

1. 학급 이름과 적용 기간을 적습니다.
2. 학생 명단과 학급 역할을 한 줄에 하나씩 적습니다. (두 개수가 같아야 해요)
3. **🎲 역할 배정하기**를 누르면 카드로 결과가 나타납니다.
4. **🖨️ A4 인쇄하기**를 눌러 인쇄합니다.
   - 인쇄 창에서 **"배경 그래픽"** 옵션을 켜야 카드 색이 함께 인쇄됩니다.

입력한 명단과 결과는 지금 쓰는 브라우저에만 저장되어 새로고침해도 남아 있습니다.
**↩️ 예시 데이터로** 버튼을 누르면 처음 예시로 돌아갑니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 구조 |
| `style.css` | 파스텔톤 디자인, A4 인쇄 스타일 |
| `script.js` | 랜덤 배정, 인쇄, 브라우저 저장, 시트 연동 로직 |
| `apps-script/Code.gs` | 구글 스프레드시트에 붙여 넣는 Apps Script 코드 |

## 구글 스프레드시트 연동

### 처음 한 번 설정하기
1. 구글 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 전부 복사해 붙여 넣고 저장(💾)합니다.
3. 위쪽 함수 목록에서 **setupSheet**를 고르고 **▶ 실행**을 누릅니다.
   - 권한 요청 창이 뜨면 내 계정을 고르고 허용합니다.
     ('확인되지 않은 앱' 경고가 나오면 **고급 → (안전하지 않음)으로 이동**을 누르세요. 내가 만든 코드라 괜찮습니다.)
   - 스프레드시트에 **명단** 시트가 예시 데이터와 함께 생깁니다.
4. **배포 → 새 배포 → 톱니바퀴 ⚙️ → 웹 앱**을 고르고
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   로 정한 뒤 배포합니다. 나오는 **웹 앱 URL**(…/exec)을 복사합니다.
5. 앱에서 **⚙️** 버튼(또는 🔄 시트 불러오기)을 누르고 복사한 주소를 붙여 넣습니다.

### 쓰는 방법
- **명단** 시트의 A열에 학생 이름, B열에 학급 역할을 적습니다. (1행은 제목)
- **🔄 시트 불러오기**를 누르면 앱의 명단이 시트 내용으로 바뀝니다.
- **💾 시트에 결과 저장**을 누르면 **배정결과** 시트에 날짜와 함께 차곡차곡 쌓입니다.

### 알아 두기
- 웹 앱 주소는 GitHub 코드에 넣지 않고, 앱을 쓰는 **브라우저에만** 저장됩니다.
  다른 컴퓨터에서 쓸 때는 ⚙️ 버튼으로 한 번 더 입력하세요.
- 이 주소를 아는 사람은 명단을 볼 수 있으니 다른 사람에게 공유하지 마세요.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.
  (이렇게 하면 주소가 바뀌지 않아요.)
