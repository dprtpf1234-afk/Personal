# 🌈 우리 반 1인 1역할

학생과 학급 역할을 무작위로 1:1 짝지어 주는 웹 앱입니다.
교실 게시판에 붙일 수 있도록 A4 한 장 인쇄도 지원합니다.

## 사용 방법

1. 학급 이름과 적용 기간을 적습니다.
2. 학생 명단과 학급 역할을 한 줄에 하나씩 적습니다. (두 개수가 같아야 해요)
3. **🎲 역할 배정하기**를 누르면 카드로 결과가 나타납니다.
4. **🖨️ A4 인쇄하기**를 눌러 인쇄합니다.
   - 인쇄 창에서 **"배경 그래픽"** 옵션을 켜야 카드 색이 함께 인쇄됩니다.

입력한 명단과 결과는 지금 쓰는 브라우저에만 저장되어 새로고침해도 남아 있습니다.
**↩️ 예시 데이터로** 버튼을 누르면 처음 예시로 돌아갑니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 구조 |
| `style.css` | 파스텔톤 디자인, A4 인쇄 스타일 |
| `script.js` | 랜덤 배정, 인쇄, 브라우저 저장, 시트 연동 로직 |

## 구글 스프레드시트 연동 (준비 중)

상단의 **🔄 시트 불러오기**, **💾 시트에 결과 저장** 버튼은 자리만 만들어 둔 상태입니다.
Apps Script 웹 앱을 배포한 뒤 `script.js` 맨 위의 `CONFIG.SHEET_API_URL`에
배포 주소를 넣으면 연결됩니다. 주고받는 데이터 형식은 `script.js`의 7번 구역 주석을 참고하세요.
